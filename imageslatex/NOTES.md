# Figures

This folder contains the figures used in the seminar paper that were generated by the project scripts (plots, confusion matrices, descriptor statistics).

**Figures that show photographs of wounds are intentionally not included**, out of respect for the patients in the images:

- `Figure 2026-09-15 125409 (16).png`: sample images per class
- `Figure 2026-09-17 181124.png`: wound segmentation masks
- `Figure 2026-09-17 180034.png`: contour examples (successful and problematic)
- `gradcam_sdti_aug.png`, `gradcam_stageIII_greska.png`: Grad-CAM overlays

To reproduce them, download the dataset and run `5_train_pipeline.py` (Grad-CAM) and `6_classical_cv.py` (segmentation, contours) from the repository root.

Datasets:
- original set: https://www.kaggle.com/datasets/sinemgokoz/pressure-ulcers-stages
- expanded set: https://www.kaggle.com/datasets/divyanshmahajan2311/pressure-ulcers-detection
